# P0 基线判定报告：不通过，回特征/标签层

- **日期**：2026-10-17
- **执行阶段**：第 12 章路线的 P0（基线）
- **被测模式**：仅做多 × 主流（1h K 线 → 12h 预测/持仓）
- **判定**：❌ **不通过** —— 触发设计书 1.4 节与第 12 章 P0 的终止条件
- **后续动作**：回特征工程与标签层，暂不进入 P1（Chronos 门控）

## 1. 实验设置

| 项 | 值 |
|---|---|
| 工具 | `nofx-ml-rolling-benchmark`（release 构建） |
| 数据 | `data/ml/expanded-archive-20261016`，币安 USD-M 永续 1h K 线 |
| 区间 | 2026-04-06T08:00Z → 2026-10-14T00:00Z（4576 小时 ≈ 190.7 天） |
| 标的 | 按小时成交额中位数取前 20 |
| 滚动窗口 | 训练 1080h → 测试 336h；标签/持仓周期 12h |
| 样本外折数 | 10（测试窗口零重叠） |
| 成本 | taker 6.0 bps + 滑点 5.0 bps = 11.0 bps/边，往返 22.0 bps |
| 模型 | LightGBM 回归（120 棵树、25 个因果特征、CPU） |
| 变量 | `threshold_multiple` ∈ {1.0, 2.0, 3.0, 5.0}，即仅当 \|预测 12h 收益\| > 该倍数 × 往返成本时才持仓 |

三个基线共用同一成本模型：LightGBM、SMA24/96 趋势、买入持有。

| 2.0 | -18.75% | -41.89% | -1.790 | -26.73% | 11.54 | 120.7 | 92.4% |
| 3.0 | -17.25% | -39.05% | -1.839 | -23.69% | 7.85 | — | — |

### 2.2 毛收益 vs 成本拖累（关键）

`cost_drag = gross_return − net_return`（`rolling_bench::Performance` 定义），因此 `gross = net + drag`：

| threshold_multiple | 毛收益 | 成本拖累 | **净收益** |
|---:|---:|---:|---:|
| 1.0 | **-0.06%** | -17.37 pp | -17.43% |
| 2.0 | -7.21% | -11.54 pp | -18.75% |
| 3.0 | -9.40% | -7.85 pp | -17.25% |
| 5.0 | -7.05% | -4.51 pp | -11.56% |

### 2.3 胜率视角

| threshold_multiple | 折数胜出 | 标的胜出 |
|---:|---:|---:|
| 1.0 | 4/10 | 5/20 |
| 2.0 | 3/10 | 7/20 |
| 3.0 | 3/10 | 7/20 |
| 5.0 | 5/10 | 9/20 |

`edge vs trend` 全档为负（-18.58% ~ -12.71%）。即便在最宽松的阈值下，模型也只在 5/20 个标的上跑赢被动趋势。

## 3. 结论：三条

### C1 亏损几乎 100% 来自交易成本，毛收益≈0

thr=1.0 时毛收益 **-0.06%**，即模型在**不计费的理想世界里收益为零**。17.37 个百分点的亏损全部是手续费与滑点。

### C2 "降换手"能减亏，但**无法转正**——这修正了设计书的原始判断

提高门槛使换手从 173.4 降到 45.2、成本拖累从 17.37pp 降到 4.51pp，净收益由 -17.43% 收敛到 -11.56%。看起来在改善，但：

- 毛收益同时也从 -0.06% 掉到 -7.05%
- 净收益的**理论上限就是毛收益**，而最好的毛收益是 -0.06%

> 因此设计书 1.4 节推论 2 中"降换手是通往盈利的关键路径"这一表述**需要修正**。准确表述是：
> **换手是唯一的亏损来源，但降换手只能把损失收敛到零，不能使其转正。要盈利，信号必须先在毛收益层面产生正的边际，而这目前不存在。**

阈值提高后毛收益反而恶化，说明被过滤掉的不是噪声，而恰恰是模型与收益之间的那点微弱（可能是偶然的）关联。

### C3 因此 P0 终止条件成立

设计书 1.4 节与第 12 章列明的 P0 验收第 ② 项为：**"扣 `research::costs()` 后净收益必须转正，否则终止，回到特征/标签层"**。

实测 -17.43% ~ -11.56%，全档为负 → **判定不通过，按约定回特征工程与标签层，不进入 P1。**

## 4. 附带发现：标的池存在非加密货币污染（必修）

自动选出的前 20 标的为：

```
BTCUSDT, ETHUSDT, SOLUSDT, XAUUSDT, ZECUSDT, XRPUSDT, XAGUSDT, HYPEUSDT,
CLUSDT, DOGEUSDT, BNBUSDT, BZUSDT, 1000PEPEUSDT, SUIUSDT, NEARUSDT,
ADAUSDT, WLDUSDT, TAOUSDT, ENAUSDT, LINKUSDT
```

其中 **XAUUSDT（黄金）、XAGUSDT（白银）、CLUSDT（WTI 原油）、BZUSDT（布伦特原油）共 4 个（占 20%）并非加密货币**，而是币安的商品/贵金属计价永续合约。

影响：

- 它们的波动结构、交易时段、驱动因素与 crypto 完全不同，混入训练会稀释/污染信号
- 这与"虚拟币组合"的标的口径直接冲突
- 今日 15m 归档采集时这 4 个已被活跃合约清单拒绝（见工作日志），但 1h 归档里仍在

**要求**：在币种筛选层增加"合约类型/标的类别"白名单，只保留 crypto 永续；该过滤必须在 universe 构建阶段（流动性排名之前）执行，不得只在回测入口临时剔除。此项列为 P0 的修复项，修复后基线需重跑。

## 5. 下一步建议（按优先级）

| 优先级 | 动作 | 说明 |
|---|---|---|
| P0-1 | **修标的池污染** | 加 crypto 白名单过滤，重跑基线 |
| P0-2 | **做"零信号"基线对照** | 用随机方向/恒定方向的假信号跑同一引擎，确认 -17% 中究竟多少是成本结构、多少是模型负 alpha；若随机信号也亏这么多，说明是成本/频率问题而非模型问题 |
| P0-3 | **降低交易频率再测** | 当前持仓占比 94%，几乎一直在场。尝试"每 12h 只取 top-k 最强信号"或"仅在 |预测| 超过 2–3 倍成本 + 方向一致时交易"，把换手压到 20 以下看毛收益是否转正 |
| P0-4 | **检查标签是否可学** | 若 12h 三分类标签在扣除 51.5 bps 后基本是噪声，应重新评估标签定义（改回归 + 分位数、或拉长 horizon 到 24/48h） |
| — | 暂缓 P1 及之后 | 在 P0 未通过前，做 Chronos 门控、组合分配标定均无意义 |

## 6. 可复现命令

```bash
cd /d/UGit/nofx-new
cargo build --release --bin nofx-ml-rolling-benchmark

for t in 1.0 2.0 3.0 5.0; do
  env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY \
      -u http_proxy -u https_proxy -u all_proxy \
    ./target/release/nofx-ml-rolling-benchmark \
      --data-dir data/ml/expanded-archive-20261016 \
      --output-dir output/p0-baseline-thr$t \
      --threshold-multiple $t
done
```

产物：`output/p0-baseline-thr*/{report.md,report.json,equity.csv}`；

## 7. 结论的适用边界

- 仅 1h K 线、12h 预测、20 标的、190 天样本（2026-04 至 2026-10）
- 该区间为强上涨行情（Buy&Hold +29.28%），**未包含完整熊市与高波动震荡段**，结论在下行市中是否成立未知

- 成本模型为 `research::costs()` 固定假设，非交易所逐笔重建
