# 2026-10-14 本机小模型买入审核实测

**本机运行可行；本次 Qwen2.5 0.5B 配置不适合独立决定买入。** 24 个历史信号全部被模型放行，8 个明显不合格计划也全部被模型判为买入。模型没有增加筛选，危险计划由 Rust 风控拦截。

## 本机运行

Intel i5-10400，约 24 GB 内存，无独立显卡。使用 llama.cpp b11429、Qwen2.5-0.5B-Instruct Q4_K_M、4 个 CPU 线程、4096 上下文、单个请求。

模型文件约 491 MB，官方 SHA-256 校验通过。服务进程在实验结束时占用约 708 MiB，观察到的峰值约 748 MiB。24 次历史审核平均耗时 3.72 秒，范围 2.94～4.80 秒；不是全市场并发吞吐量。

服务保留在 `http://127.0.0.1:18080/v1`，模型 ID 为 `qwen2.5-0.5b-instruct`。安装与重复运行说明见 [本机模型说明](../docs/local-buy-model.md)。

## 历史对照

固定 BTCUSDT 15 分钟数据，研究时间为 2026-09-08 20:42～10-02 20:42（UTC+08）。从 133 个有效本地规则做多候选中预先均匀选择 24 个，每个输入使用此前 80 根已收盘 K 线。模型不接收未来价格或成交结果，原先封存的最终区间未参与候选或结果结算。

模拟复用生产 Rust 策略计划规范化、paper/simulator 成交和成本规则。每笔计划独立模拟 100 USDT 保证金、1 倍杠杆。成本为单边费用 6 bps、滑点 5 bps、资金费 3 bps/8h。

## 不合格计划

模型 API 和 JSON 解析均成功，历史样本、负例中没有请求或格式错误。但负例的原始模型判断全部为 `BUY`：

| 明显不合格输入 | 模型判断 | Rust 风控后的判断 |
| --- | --- | --- |
| 止损高于入场价 | BUY | WAIT |
| 止盈低于入场价 | BUY | WAIT |
| 行情已过期 | BUY | WAIT |
| 信号不可交易 | BUY | WAIT |
| 扣费后盈亏比只有 0.6 | BUY | WAIT |
| 趋势证据缺失 | BUY | WAIT |
| 只有 20 根 K 线 | BUY | WAIT |
| 极端波动 | BUY | WAIT |

模型自行拒绝率为 **0/8**；程序保护拦截为 **8/8**。部分理由还错误声称条件满足，例如 `dataFresh=false` 时仍输出“数据满足所有条件”。两个可讨论的合成正例也均得到 BUY。

3 个历史输入各重复两次，三组买入判断一致，但部分解释文本变化。一致性不能弥补错误判断。

## 格式与简单指令复核

追加 9 次独立诊断：明确要求 BUY/WAIT、简单 `eligible` 条件判断，以及 BUY 优先、WAIT 优先的两种枚举顺序和不加 schema 的输出。

8/9 次同时满足预期判断和严格 JSON 格式。两种 schema 的 5 次全部通过，明确要求 WAIT 时无论枚举顺序如何都能返回 WAIT；没有把输出强制锁定为 BUY 的证据。无 schema 的 4 次中有 1 次不能按严格 JSON 解析。

所以复杂买入审核中的全部误放行应视为本次模型与提示配置的有效性失败，不能用 JSON 约束固定答案来解释。这个诊断也不证明简单条件识别足以判断交易获利。
