# 策略判断与参数复核（2026-10-09）

本次确认了策略计算、过滤开关和参数传递的问题，已直接修复。没有依据小样本放宽默认信号门槛，也没有把规则分数替换成未经验证的胜率。

## 已修复

| 位置 | 原行为 | 修复 |
| --- | --- | --- |
| 增强趋势 MACD | 快 EMA 从慢 EMA 起点才继续更新，中间历史被跳过；影响入场动量与智能退出 | 复用共享 SMA 初始化的完整 EMA/MACD 序列，并检查无效周期 |
| 计划标准化 | 仅读取顶层推荐杠杆，忽略策略写在 `plan.recommendedLeverage` 的值；测试中推荐 2 倍变成 5 倍 | 保留有效的顶层或计划内推荐杠杆；两者均无效时才使用原有回退计算 |
| 4H 突破与吊灯突破 | 信号有评分，但计划中的 `signalScore` 固定为 0 | 计划保存同一信号评分，使按评分分配仓位时能读取真实分数 |
| 4H 指标过滤 | ADX 未就绪时，均值回归的 ADX 上限过滤被跳过 | 启用 ADX 过滤时必须有有效 ADX；RSI 未就绪也等待 |
| 妖币 15m 趋势确认 | 关闭确认后返回的对象没有 `ok`，后续仍按失败拦截 | 只在开关启用时要求 `ok` |
| 增强趋势参数关系 | 快慢周期、量比窗口可相互冲突，导致指标无效或解释不清 | 冲突时明确观望，显示参数冲突原因；数据不足提示实际所需根数 |
| 增强趋势量比上限 | 上限硬编码 1.2，但最低量比允许设到 5；两者可造成永久无信号 | 增加 `maxVolumeRatio`，默认仍为 1.2；0 关闭上限，并检查与最低量比的冲突 |

新增 8 项 Rust 回归测试。其中最先加入的 7 项在修改前均失败，复现了旧行为。迁移 JSON fixtures 保持原样；对照测试仅对已修复的突破 `signalScore` 使用 fixture 原有的信号评分，其他字段继续比较。

## 参数诊断

- 妖币方向概率由当前校准函数固定返回 **46.34%**，在线策略的 `minProbabilityPct` 为 **50%**。即使原始规则分数很高，也无法通过该概率条件。这是确定的阻断原因。没有降低门槛或虚增概率，后续需用新的训练样本重新校准。
- 增强趋势默认量比可入场区间为 **0.8 < 量比 < 1.2**。原来把下限提高到 1.2 及以上会完全禁止入场。现在可见、可配置、可识别冲突，默认行为保持不变。
- 现有月度基线中，增强趋势有成交但收益为负；其他策略多数样本不足。4H 均值回归和妖币零成交不能作为参数有效或无效的收益证据。
- 当前在线全局置信度为 **0.45**，冻结研究快照为 **0.65**。本次代码对照保持快照 0.65，避免混入门槛调整的影响。
