# Chronos + LightGBM 分阶段优化计划（2026-10-16）

目标是在固定仓位与风险上限下，提高可复核的成本后收益。现有模型、旧数据与 Demo 配置保持原样，新数据、缓存、候选与报告另存；不以提高分类准确率代替盈利验证。

| 顺序 | 工作 | 产物与验收 |
| --- | --- | --- |
| 1 | 扩充180天官方历史，纳入有真实归档的历史合约 | UTC `[2026-04-17,2026-10-14)`，另加256小时预热；SHA-256校验，月归档优先、日归档补边界；缺失、上市/退市时点明确记录，不插值、不把当前币种数量当历史全集 |
| 2 | 对齐交易标签 | 因果特征只用信号时点已收盘数据；多空分别走共享 Rust 成交、费用、风控、分批止盈、移动保护和退出规则；48小时成熟边界，未结算或无有效成交样本排除；保留终值涨跌标签作对照 |
| 3 | 多窗口训练与 LightGBM 调参 | 三个扩展训练窗口，验证、概率校准、确认时间段分开；16组预先固定训练候选，验证概率损失筛选后用共享回放比较；独立温度校准；保留无 Chronos 特征消融 |
| 4 | 优化 Chronos 预测与评估权重微调 | 中位预测偏差与区间宽度分别校准；先确认 Chronos 对交易结果有跨窗口增益，再评估权重训练；CPU/训练运行库与 Rust 工具链可行性单列，不把后处理校准称作权重微调 |
| 5 | 冻结候选与验证 | 独立保存选择与来源哈希后计算最终历史保留段；同一共享引擎、成本和风险限额；真实前向验证使用冻结后新增数据 |

数据与输出目录分别为 `data/ml/expanded-archive-20261016`、`output/ml-rolling-20261016`，缓存按币种分文件、绑定来源和实现指纹，支持断点继续，不能混用旧标签或不同规则。

每个时间分区只允许 `origin + 48小时 <= 分区结束` 的标签进入该分区，防止48小时交易结果穿过训练/验证边界。最后20天作为历史保留段；各滚动确认段不能回流同一窗口的选择。此前已观察过的10月历史不称全新盲测。

LightGBM 搜索涵盖叶数、深度、最小叶样本、学习率、轮数预算、L1/L2与采样；已实现每5轮检查、30轮未改善即停止的验证集早停，并恢复最佳模型。概率温度只在独立校准段拟合。Chronos 单变量预测继续作为价格特征，历史资金费、持仓、多空比等只通过其真实可用时间进入 LightGBM。

初步晋级条件预先固定：各确认段与最终历史保留段成本后净收益为正、相对同口径基线改善、至少50笔已平仓交易、无未结订单、最大单币回撤不恶化且不超过10%。独立单币账户合计不能冒充 Demo 共享资金组合收益。

目前纸面共享引擎与 Demo 存在入场调度差异，最终报告必须保留这一限制。模型替换前还需对齐实际 Demo 的发单时序、共享账户预算与交易所过滤，并完成足量新数据的前向验证；回测通过不自动修改运行配置。

全部新增训练、标签、回放和优化业务使用 Rust。PowerShell 仅负责构建、顺序调用与日志，不实现另一套收益计算；不新增 Python/Node 回测逻辑。修改后执行 `cargo fmt --check`、`cargo check --all-targets`、`cargo test --all-targets` 及对应数据/回放验收。

方法依据：[LightGBM 官方调参说明](https://lightgbm.readthedocs.io/en/latest/Parameters-Tuning.html)；[Chronos-Bolt 官方微调示例](https://auto.gluon.ai/1.3.1/tutorials/timeseries/forecasting-chronos.html#fine-tuning)。

统一执行入口：`powershell -File scripts/improve-ml-model.ps1`；断点继续加 `-Resume`。构建和业务均由 Rust 工具完成；脚本只顺序调用采集与训练，把当前阶段写到 `output/ml-rolling-20261016/workflow-status.json`。独立日志为 `collection.*.log`、`training.*.log`；训练完成后生成 `report.md`、`report.json` 和逐窗口、逐币回放。脚本只在采集成功后进入训练，任一步失败写明原因并停止，不跳过错误继续发布模型。

已在外部启动采集进程时，可用 `-SkipBuild -CollectorProcessId <采集进程ID>` 接续：等待该进程退出并确认辅助数据阶段完成后再训练，不启动第二个采集器。该参数只用于当前确知的本地采集进程。
