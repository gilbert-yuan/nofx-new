## API调用链路

### 场景：分析一个币种并下单

```
用户触发
   ↓
┌──────────────────────────────────────────────┐
│ globalAutomation.runAnalysis()               │
└───────────────┬──────────────────────────────┘
                │
                ├─> 1. 读取配置
                │   └─> store.getConfig()
                │
                ├─> 2. 获取合约列表
                │   └─> market.perpetualUsdtContracts()
                │       └─> OKX API: GET /api/v5/public/instruments
                │
                ├─> 3. 预筛选 (Super模式)
                │   └─> superAnalysis.preFilter(symbols)
                │       └─> coinGecko.getMarketData(symbols)
                │           └─> GET https://api.coingecko.com/api/v3/coins/markets
                │
                ├─> 4. 获取K线
                │   └─> getFreshMarket(symbol, '1m')
                │       ├─> 尝试: marketDb.listKlines(...)
                │       │   └─> PostgreSQL: SELECT * FROM klines
                │       └─> 回退: market.klines(...)
                │           └─> OKX API: GET /api/v5/market/candles
                │
                ├─> 5. 执行分析
                │   └─> superAnalysis.analyze(market)
                │       │
                │       ├─> 5.1 本地分析
                │       │   └─> enhancedAnalysis(market)
                │       │       ├─ 计算均线、ATR、MACD、RSI...
                │       │       └─> 返回初始评分: 75/100
                │       │
                │       ├─> 5.2 市场数据
                │       │   └─> coinGecko.getMarketData([symbol])
                │       │       └─> GET https://api.coingecko.com/.../markets
                │       │
                │       ├─> 5.3 市场情绪
                │       │   └─> fearGreed.getCurrentIndex()
                │       │       └─> GET https://api.alternative.me/fng/
                │       │
                │       ├─> 5.4 技术指标验证 (可选)
                │       │   └─> alphaVantage.getRSI(symbol)
                │       │       └─> GET https://www.alphavantage.co/query?...
                │       │
                │       └─> 5.5 综合评分
                │           └─> 返回: {action:'BUY', score:75, confidence:0.65}
                │
                ├─> 6. 保存分析记录
                │   └─> archive.save(record)
                │       └─> 文件系统: data/research/${date}/${id}.json
                │
                ├─> 7. 提交订单
                │   └─> simulation.submit({symbol, margin:100, leverage:3})
                │       └─> simulation.mutate(...)
                │           └─> PostgreSQL: UPDATE simulated_account
                │
                └─> 8. 记录日志
                    └─> console.log('[GlobalAutomation] BTCUSDT已提交...')
```

### 场景1：查看持仓并手动复核

```bash
# 1. 查看当前持仓
curl http://127.0.0.1:3100/api/paper/account | jq '.orders[] | select(.status=="open") | {
  symbol,
  direction,
  entry,
  markPrice,
  unrealized,
  stopLoss: .plan.stopLoss,
  takeProfit: .plan.takeProfit
}'

# 输出：
# {
#   "symbol": "BTCUSDT",
#   "direction": "OPEN_LONG",
#   "entry": 50000,
#   "markPrice": 50500,
#   "unrealized": 9.85,
#   "stopLoss": 49200,
#   "takeProfit": 51600
# }

# 2. 手动触发复核
curl -X POST http://127.0.0.1:3100/api/automation/tasks/positionReview/trigger

# 3. 查看复核历史
curl http://127.0.0.1:3100/api/paper/account | jq '.orders[0].reviewHistory[-3:]'

# 输出：
# [
#   {
#     "at": "2026-09-08T10:30:00.000Z",
```
