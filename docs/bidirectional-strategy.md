# 本地规则策略的双向交易

本地单周期、多周期、增强和超级增强引擎默认允许多空两个方向。此前共享规则将 `LONG_ONLY.enabled` 固定为 true，且两个本地分析入口另有无条件禁空分支，导致空头信号总是被转为 WAIT。

现在这些入口统一遵守 `NOFX_LONG_ONLY`：未设置或设置为 `false` 时允许双向，显式设为 `true` 或 `1` 时仅允许做多。超级增强引擎继承增强引擎的基础信号。这个开关作用于本地规则信号，不是实盘交易所权限或 AI/手工订单的全局开关。

恢复双向不等于强制开空。趋势共振、量能、评分、避免追空、盈亏比、资金和重复持仓检查继续生效；已有同币种持仓也不会自动反手。环境变量在模块加载时读取，修改后需要重启服务。

同时修正了三个空头相关问题：

- 单周期策略使用绝对偏离距离，双向过滤离均线过远的入场。
- 增强策略按空头最不利入场价 entryMin 计算止损风险距离和推荐杠杆。
- RSI 为 0 仍参与评分、超卖过滤和持仓退出建议，不能当作缺失数据。

回归测试包含确定性空头行情生成 SELL、研究计划校验、模拟 OPEN_SHORT 提交及下跌止盈结算，也验证 BUY 路径、显式禁空配置和多周期冲突过滤。这些是功能正确性检查，不是收益回测。
