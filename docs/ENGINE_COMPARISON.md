## 🔍 详细对比

### 1. 原版本地规则 (localAnalysis)

**技术指标**：
- 20/50均线
- 14根ATR

**开仓逻辑**：
```javascript
if (MA20 > MA50 && close > MA20) {
  action = 'BUY';
}
```

**优点**：
- ✅ 超快速度
- ✅ 零依赖
- ✅ 简单易懂

**缺点**：
- ❌ 假信号多
- ❌ 无动量确认
- ❌ 固定止盈止损

**适用场景**：
- 快速测试
- 系统验证
- 学习参考

---

### 2. 增强版本地规则 (enhancedAnalysis) ⭐ 推荐

**技术指标**：
- 20/50均线（趋势）
- 14根ATR（波动）
- MACD（动量）
- RSI（强弱）
- 布林带（极值）
- 成交量（确认）
- 支撑阻力（优化）
- 综合评分（过滤）

**开仓逻辑**：
```javascript
综合评分 = 
  均线排列(25分) + 
  MACD动量(20分) + 
  RSI健康(15分) + 
  布林带位置(15分) + 
  成交量确认(15分) + 
  波动率(10分)

if (评分 >= 60 && 
    风险收益比 >= 1.2 &&
    MACD确认) {
  action = 'BUY';
}
```

**优点**：
- ✅ 假信号显著减少
- ✅ 多重信号确认
- ✅ 三级止盈目标
- ✅ 智能移动止损
- ✅ 主动识别退出信号
- ✅ 无需API Key
- ✅ 100分评分系统

**缺点**：
- ⚠️ 速度略慢（+60%）
- ⚠️ 开仓频率较低

**适用场景**：
- ⭐ 日常使用（推荐）
- ⭐ 长期运行
- ⭐ 追求稳定盈利

---

### 3. AI分析 (analyzeMarkets)

**技术指标**：
- 全面技术分析
- 多周期验证
- 市场结构分析
- 风险评估

**开仓逻辑**：
```
AI模型综合判断，考虑：
- 所有技术指标
- 市场情绪
- 历史模式
- 风险收益比
```

**优点**：
- ✅ 最全面分析
- ✅ 最高理论胜率
- ✅ 详细分析报告
- ✅ 自然语言输出

**缺点**：
- ❌ 需要模型API Key
- ❌ 速度最慢
- ❌ 网络依赖
- ❌ 成本较高

**适用场景**：
- 重要决策
- 高价值交易
- 深度研究

## 🔧 配置方法

### 切换分析引擎

**方法1：配置文件（推荐）**
```json
// data/config.json
{
  "analysis": {
    "useEnhanced": true   // true=增强版, false=原版
  }
}
```

**方法2：代码修改**
```javascript
// server/globalAutomation.js:168
const useEnhanced = true;  // 改为 false 使用原版
```

### 调整增强版参数

```javascript
// server/enhancedAnalysis.js

// 行149: 评分要求
if (trendStrength.score < 60) {  // 改为55/65/70

// 行328: 风险收益比
if (riskRewardRatio < 1.2) {  // 改为1.0/1.5

// 行91-150: 各指标权重
score += 25;  // 均线（可改为20/30）
score += 20;  // MACD（可改为15/25）
score += 15;  // RSI（可改为10/20）
```
