# Flutter 端优化说明

## 优化概览

本次优化使 Flutter 应用能够完成单币盯盘、K线图查看、AI分析和详情页面，并直接从交易所与 AI API 获取数据，通过本地 SQLite 保存缓存与历史记录。

## 主要改进

### 1. 新增币种详情页 (`coin_detail_page.dart`)

创建了全新的币种详情页面，提供完整的单币种分析功能：

- **价格信息展示**
  - 大号币种名称和代码
  - 当前价格（格式化显示）
  - 24小时涨跌幅
  - 市场排名

- **统计数据卡片**
  - 市值
  - 周期最高价
  - 周期最低价
  - 周期涨跌幅

- **K线图增强**
  - 更大的图表显示（280px高度）
  - 改进的网格线显示
  - 实时刷新功能
  - 周期和K线数量显示

- **最新分析结果**
  - 操作建议（做多/做空/平多/平空/观望）
  - 信心度百分比
  - 仓位建议
  - 判断依据
  - 风险提示
  - 执行建议
  - 生成时间

- **历史分析记录**
  - 显示最近5条分析记录
  - 快速查看操作类型和信心度
  - 时间线展示

- **快速操作**
  - 悬浮按钮：快速分析当前币种
  - 顶部刷新按钮：更新K线数据
  - 菜单按钮：更多操作

### 2. 改进主页面交互

#### 币种列表增强
- 每个币种右侧添加箭头图标
- 点击箭头跳转到币种详情页
- 点击币种主体区域：选中并加载到工作台
- 添加提示文字："点击右侧箭头查看详情"

#### 分析结果卡片可点击
- "工作台"页面的结果卡片可点击
- "当天总结"页面的结果卡片可点击
- 点击后直接跳转到对应币种详情页
- 卡片右侧显示前进箭头图标

### 3. 数据流优化

- 详情页自动选择并获取对应币种数据
- 统一使用 `ResearchController` 管理状态
- 页面间数据实时同步
- 分析完成后自动更新详情页
- 交易所或 AI 接口不可用时优先使用 SQLite 中的 K线、币种和分析缓存

### 4. 视觉改进

- 使用圆角卡片设计（12px圆角）
- 一致的颜色系统：
  - 绿色：做多/上涨
  - 红色：做空/下跌
  - 橙色：观望
- 改进的图标使用
- 更好的信息层次结构
- 响应式布局适配

## 功能验证

### 单币盯盘 ✅
- 支持选择一个币种作为当前盯盘标的
- 支持按周期和K线数量拉取数据
- 支持定时自动刷新
- 支持从详情页刷新K线和发起AI分析

### 本地 SQLite 持久化 ✅
- `klines` 保存按币种、周期和开盘时间去重的K线
- `analyses` 保存 AI 分析结果和历史记录
- `settings` 保存当前币种、刷新和策略配置
- `cache` 保存币种目录及其他本地缓存
- 应用重启后可恢复缓存数据和分析历史

### 获取币种K线图 ✅
- 单个币种K线获取
- 支持不同周期（1h、4h、1d等）
- 可配置K线数量（20-200根）
- API 成功后自动写入 SQLite
- API 暂时不可用时从 SQLite 恢复

### AI分析 ✅
- 直接调用 AI API 的单币分析接口
- 支持做多、做空、平多、平空、观望五类结果
- 保存分析结果到 SQLite
- 可在详情页查看当前结果和历史结果

### Windows 窗口能力 ✅
- 支持窗口置顶
- 支持紧凑悬浮窗口
- 支持无边框标题栏拖动
- 支持手动调节窗口透明度
- 鼠标移出窗口或窗口失焦时自动降低透明度
- 鼠标移回窗口并获得焦点后恢复设定透明度

## 使用指南

### 查看币种详情的方式

1. **从币种列表**
   - 在"分析工作台"页面
   - 找到想查看的币种
   - 点击右侧的 `>` 箭头图标

2. **从分析结果**
   - 在"当天总结"或"分析工作台"页面
   - 点击任意分析结果卡片
   - 自动跳转到对应币种详情

3. **详情页操作**
   - 点击右上角刷新图标：更新K线数据
   - 点击悬浮按钮"分析此币种"：执行分析
   - 点击菜单按钮：查看更多选项

### 分析币种的方式

1. **单个分析**
   - 在币种列表点击币种名称（选中）
   - 点击"分析当前"按钮
   - 或进入详情页点击悬浮按钮

2. **直连配置**
   - 在"策略设置"中填写交易所行情地址、AI API 地址和 AI API Key
   - 同时配置策略名称、模型名称、系统提示词和分析规则
   - 保存后客户端直接同步交易所币种、K线并请求 AI 分析

### K线获取方式

1. **单个获取**
   - 选中币种后点击"获取K线"按钮
   - 或在详情页点击刷新图标

2. **本地恢复**
   - API 请求失败时自动读取 SQLite 缓存
   - 缓存数据库文件名为 `nofx_research.sqlite`
   - 数据库位于系统应用支持目录，不与项目源码混放

## 技术细节

### 新增文件
- `lib/src/coin_detail_page.dart` - 币种详情页面组件
- `lib/src/services/database_service_io.dart` - IO 平台 SQLite 实现
- `lib/src/services/database_service_web.dart` - Web 平台兼容实现
- `lib/src/services/window_service_io.dart` - Windows 窗口实现
- `lib/src/services/window_service_web.dart` - Web 平台兼容实现

### 修改文件
- `lib/src/app.dart` - 添加详情页导航，优化交互
- `lib/src/research_controller.dart` - 接入交易所/AI 直连、SQLite、自动刷新和窗口状态
- `lib/src/models.dart` - 对齐交易所/AI 直连和 SQLite 数据模型
- `lib/main.dart` - 导出 NofxApp 类
- `test/widget_test.dart` - 修复测试用例

## 性能优化

- 使用 `AnimatedBuilder` 减少不必要的重建
- K线图使用 `CustomPainter` 高效渲染
- 列表使用 `ListView.builder` 按需构建
- 状态管理使用 `ChangeNotifier` 模式
- 请求期间按区域显示加载状态，避免锁死整个页面
