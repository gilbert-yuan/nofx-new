# NOFX 研究工作台 - 使用指南

## 快速开始

### 运行应用

```bash
cd flutter_app
flutter run
```

## 核心功能

### 1️⃣ 查看币种详情

#### 方法一：从币种列表进入
1. 打开 **分析工作台** 页面
2. 在左侧币种列表中找到目标币种
3. 点击币种右侧的 **→** 箭头图标
4. 进入币种详情页

#### 方法二：从分析结果进入
1. 在 **当天总结** 或 **分析工作台** 页面
2. 点击任意分析结果卡片
3. 自动跳转到对应币种详情页

### 2️⃣ 获取K线图

应用直接从交易所获取币种和 K 线；网络接口不可用时，会优先读取本地 SQLite 缓存。

#### 单个币种
1. 在币种列表点击币种名称（选中）
2. 点击 **获取 K 线** 按钮
3. 或进入详情页点击右上角 **刷新** 图标

#### 全部币种
1. 点击币种列表上方的 **获取全部币种** 按钮
2. 系统自动批量获取所有币种K线
3. 显示进度条和完成状态

#### 配置K线参数
- **周期**：1h / 4h / 1d
- **K线数量**：20-200 根
- 在"分析范围"卡片中调整

### 3️⃣ 分析币种

#### 分析当前币种
1. 在币种列表选中目标币种
2. 点击 **分析当前** 按钮
3. 或进入详情页点击悬浮按钮 **分析此币种**

#### 批量分析
1. 设置 **批量大小**（如 8 个）
2. 点击 **分析范围** 按钮
3. 系统自动分析前N个币种

#### 自定义分析
1. 在"自定义标的"输入框输入币种代码
2. 多个币种用逗号分隔，例如：`BTCUSDT, ETHUSDT, SOLUSDT`
3. 点击 **分析范围** 按钮

#### 全市场分析
1. 设置 **最大标的** 数量（如 30 个）
2. 点击 **分析全市场** 按钮
3. 等待批量分析完成

### 4️⃣ 查看分析结果

#### 工作台页面
- 显示当前选中币种的历史分析
- 点击卡片可跳转到详情页
- 查看操作建议、信心度、仓位等

#### 当天总结页面
- 聚合最新的分析结果
- 统计数据：已分析标的、可执行信号、做多/做空倾向
- 可按操作类型筛选
- 点击卡片跳转到详情页

#### 历史分析页面
- 完整的分析历史记录
- 支持按操作类型筛选
- 可清空历史记录
- 点击查看详细信息

#### 币种详情页
- **价格信息**：当前价格、24h涨跌、市场排名
- **统计数据**：市值、周期最高/最低、周期涨跌
- **K线图**：完整的蜡烛图展示
- **最新分析**：操作建议、信心度、判断依据、风险提示、执行建议
- **历史分析**：最近5条分析记录

## 配置说明

### 分析参数

| 参数 | 范围 | 说明 |
|------|------|------|
| 周期 | 1h / 4h / 1d | K线时间周期 |
| K线数量 | 20-200 | 分析的K线根数 |
| 最大标的 | 1-300 | 全市场分析的币种数量 |
| 批量大小 | 1-20 | 每批分析的币种数量 |

### 策略参数

| 参数 | 范围 | 说明 |
|------|------|------|
| 风险阈值 | 30%-90% | 风险容忍度 |
| 保守模式 | 开/关 | 降低建议仓位 |
| 只显示可执行信号 | 开/关 | 隐藏"观望"结果 |

## 注意事项

⚠️ **重要提示**

- 本应用为**研究模式**，不执行真实交易
- 正常情况下直接从交易所和 AI API 获取真实数据
- 网络接口不可用时使用 SQLite 缓存；没有可用缓存时提示数据不可用
- 分析结果不构成投资建议
- Windows 本地 SQLite 会保存 K 线、分析历史、配置和缓存

## 常见问题

### Q: 如何查看某个币种的完整信息？
A: 点击币种列表右侧的箭头图标，或点击分析结果卡片。

### Q: 如何分析所有币种？
A: 当前版本重点支持单币盯盘；批量按钮会保留页面入口，实际分析以当前直连数据和本地缓存状态为准。

### Q: K线图不显示怎么办？
A: 确保已点击"获取K线"按钮，或刷新当前币种数据。

### Q: 如何添加自己想分析的币种？
A: 点击币种列表的"+"图标，输入币种代码（如ARBUSDT），点击获取。

### Q: 分析结果保存在哪里？
A: Windows 写入系统应用支持目录中的 `nofx_research.sqlite`，分析历史保存在 `analyses` 表，K 线保存在 `klines` 表，配置和缓存分别保存在 `settings`、`cache` 表。

### Q: 能否连接真实的交易所API？
A: 客户端直接连接交易所行情接口和 AI API，可在“策略设置”中修改交易所行情地址、AI API 地址和 AI API Key。
